# Microsoft Copilot Training Site

This repository hosts a lightweight training website for Microsoft Copilot.

## Open the training site

Open `/home/runner/work/copilot/copilot/index.html` in your browser.

Optional local server:

```bash
cd /home/runner/work/copilot/copilot
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
